# Postiz 项目中文说明

## 项目概述

- Postiz 是一个开源、可自托管的「AI 社交媒体排程与增长」平台，面向个人创作者、团队与企业，提供从内容创作、排程发布到数据分析与协作的全链路能力。  
- 项目目标是以统一的工作流与丰富集成，帮助用户在 Instagram、X（Twitter）、LinkedIn、YouTube、Reddit、TikTok、Pinterest、Slack、Discord、Mastodon、Bluesky 等平台高效管理内容与触达受众。
- 项目许可协议为 AGPL-3.0，[LICENSE](file:///d:/03.Temp/22.Postiz-app/postiz-app/LICENSE)。

## 目标用户与使用场景

- 个人创作者：需要跨平台发布与维护社交媒体活跃度。
- 内容团队与代理商：需要多人协作、素材管理、审批流程与客户交付。
- 企业营销部门：需要数据洞察、自动化排程与合规管理。
- 自动化与集成场景：通过 Public API/SDK 与第三方自动化平台（如 N8N、Make.com、Zapier）打通内容生产与投放链路。

## 核心功能

- 跨平台社交媒体排程与自动发布：支持多渠道、多账号，提供智能排程与缺失内容提醒。
- AI 辅助能力：在内容创建与优化环节提供智能建议与自动化处理。
- 数据分析与洞察：按平台与内容维度统计，衡量增长与效果。
- 团队协作与权限控制：邀请成员、分配角色、支持评论与审批。
- 集成生态：支持多种平台与第三方服务扩展，兼容自动化工具与自研业务。
- 浏览器扩展：在目标站点原生界面内辅助操作与数据采集。

## 系统架构

- Monorepo 管理：使用 pnpm Workspaces 管理多应用与共享库，[pnpm-workspace.yaml](file:///d:/03.Temp/22.Postiz-app/postiz-app/pnpm-workspace.yaml)。
- 前端应用（Next.js）：位于 [apps/frontend](file:///d:/03.Temp/22.Postiz-app/postiz-app/apps/frontend)，以 App Router 架构实现业务页面与数据接口桥接。
- 后端服务（NestJS）：位于 [apps/backend](file:///d:/03.Temp/22.Postiz-app/postiz-app/apps/backend)，提供 REST API、认证、权限与业务服务入口。
- 编排服务 Orchestrator（NestJS + Temporal）：位于 [apps/orchestrator](file:///d:/03.Temp/22.Postiz-app/postiz-app/apps/orchestrator)，负责长流程任务（发布、刷新令牌、邮件提醒等）的编排与执行。
- 浏览器扩展（Vite + React）：位于 [apps/extension](file:///d:/03.Temp/22.Postiz-app/postiz-app/apps/extension)，覆盖站点内容操作与辅助功能，[manifest.json](file:///d:/03.Temp/22.Postiz-app/postiz-app/apps/extension/manifest.json)。
- 命令服务（Commands）：位于 [apps/commands](file:///d:/03.Temp/22.Postiz-app/postiz-app/apps/commands)，包含运维与批处理任务入口。
- Node SDK：位于 [apps/sdk](file:///d:/03.Temp/22.Postiz-app/postiz-app/apps/sdk)，为外部集成提供官方数据访问与操作封装。
- 共享库（libraries）：位于 [libraries](file:///d:/03.Temp/22.Postiz-app/postiz-app/libraries)，包含数据库、第三方服务、工作流、社交平台集成等通用能力。
